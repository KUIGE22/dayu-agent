## 3. Controller 方案

采用一个 neutral private leaf `dayu/cli/_research_artifact_content.py`：

- 只拥有结构化 `ResearchArtifactContentReader` Protocol 与 bytes→text/JSON/hash helper；
- bundle closure 在全部 path 通过逐段 no-follow open/fstat 后一次生成 immutable bytes
  snapshot；
- bundle/core/helpers/workbook/routing 只增加 keyword-only optional reader 透传；
- reader 缺席时 existing caller 行为不变；reader 存在时 legacy source-tree reads 只能
  命中 snapshot；package assets 仍走原 owner；
- 不落盘正文、不复制 validator、不使用 `/dev/fd`、特殊 Path、global monkeypatch 或
  cooperative-filesystem 残余；依赖只允许 owner → neutral leaf。

这是 credible alternatives 中最小且最安全的方案：比复制 validator 更可维护，比扩大
到新的通用 filesystem framework 更窄，也不把 investment/domain 与 legacy path 细节耦合。

Controller 接受 Terra `S15-ERR-02` 的 descriptor-first 时序反例。初版文字要求“读取任一
bytes 前打开全部 leaf FD”，但 member locator 只能在 descriptor bytes strict parse 后知道，
字面不可实施。本次修订不引入第二 parser 或 filesystem framework，而把同一 root capability
下的 acquisition 收敛为：

1. descriptor component/leaf identity preflight→no-follow open→`fstat` exact，读取并保持 FD；
2. immutable descriptor payload 仅由 bundle owner 纯词法枚举 member；
3. 全部 member component/leaf identity preflight→no-follow open→`fstat` exact；
4. 全部 member FD 成功绑定后才读取 member bytes，所有 owner validator 只消费该 bytes set。

合同明确不宣称 filesystem-wide 原子快照：member preflight 前的 regular replacement 是该
member 的 current acquisition candidate，必须继续通过 owner semantics/hash；preflight→open
identity race 拒绝，open 后 pathname replacement 不能改变 FD bytes，symlink/escape/non-regular
拒绝。测试矩阵按 descriptor read、lexical enumeration、member preflight/open、全部 FD 绑定后
四个精确边界注入替换，并锁定 `BaseException` close ownership。

implementation 仍冻结；只有 Terra 与 MiM Native 对本次最终文本独立 PASS/open 0，计划才可
accepted 并恢复 B/C/D code fix。
