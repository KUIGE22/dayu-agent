### 01-未修复-[低]-advisory lock key 截断无碰撞检测

- **入口/函数**: `dayu/investment/storage/postgres_workspace_import.py:_advisory_key`
- **文件(行号)**: `_advisory_key` 函数（约第 145-164 行）
- **输入场景**: 不同 `(tenant_id, migration_id)` 对的 SHA-256 前 8 字节碰撞
- **实际分支**: SHA-256 digest 前 8 字节按 signed big-endian 解释为 int64，不同 tenant/migration 对若前 8 字节相同，会共享同一 advisory key
- **预期行为**: advisory lock 为性能优化（额外串行），不影响 correctness；但当前无碰撞检测日志或 metric
- **实际行为**: 碰撞时两不相关 import 会不必要串行，且无可观测信号
- **直接证据**: `_advisory_key` 返回 `int.from_bytes(digest[:8], byteorder="big", signed=True)`；注释已声明"hash 碰撞只会额外串行而不改变 correctness"
- **影响**: 仅性能退化，无 correctness 风险；SHA-256 碰撞概率极低（2^-32 per pair），实际无影响
- **建议改法和验证点**: 当前设计可接受。若未来增加 observability，可在碰撞时记录 debug log。无需修改。
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 低
