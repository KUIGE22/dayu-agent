## 3. 方案评估

### 方案 A（v5.3 推荐）: Protocol 前置 + DayuCliArguments 多继承

**修改 `arguments.py` 定义顺序与继承关系**:

```python
"""定义 Dayu CLI 参数的运行时类型与分派协议。

本模块只依赖 Python 标准库，集中提供 argparse 解析结果的稳定运行时身份，以及
research-template 与 write selector 所需的最小静态字段边界。
"""

from __future__ import annotations

import argparse
from typing import Protocol


class ResearchTemplateDispatchArguments(Protocol):
    """声明 research-template selector 读取的最小参数字段。"""

    research_template_action: str


class WriteDispatchArguments(Protocol):
    """声明 write dispatch selector 读取的参数字段。"""

    # boolean selector flags — Phase A
    revalidate_write_model_configuration_manual_recovery_incident_dossier: bool
    inspect_write_model_configuration_manual_recovery_incident: bool
    audit_write_model_configuration_manual_recovery_history: bool
    revalidate_write_model_configuration_manual_recovery_gate_verification: bool
    verify_write_model_configuration_manual_recovery_gate: bool
    check_write_model_configuration_manual_recovery_gate: bool
    revoke_write_model_configuration_manual_recovery_clearance: bool
    restart_write_model_configuration_manual_recovery_after_clearance_revocation: bool
    clear_write_model_configuration_manual_recovery: bool
    verify_write_model_configuration_manual_recovery: bool
    recover_write_model_configuration: bool
    # boolean selector flags — Phase B
    apply_write_model_configuration: bool
    rollback_write_model_configuration: bool
    # boolean selector flags — Phase D/F/G
    summary: bool
    preflight_only: bool
    reprice_costs: bool
    # path-valued selector flags — Phase A
    challenger_config_manual_recovery_receipt_input: str | None
    challenger_config_manual_recovery_plan_output: str | None
    challenger_config_manual_recovery_approval_output: str | None
    # path-valued selector flags — Phase F
    routing_challenger_run_approval_input: str | None


class DayuCliArguments(
    argparse.Namespace,
    ResearchTemplateDispatchArguments,
    WriteDispatchArguments,
):
    """保存 argparse 解析结果并提供稳定的运行时类型身份。

    继承 argparse.Namespace 以获得 argparse.parse_args(namespace=) 支持，
    同时通过 Protocol 多继承声明对 research-template 与 write dispatch
    selector 的 structural conformance。
    """
```

**验证结果**:

| 维度 | 结果 |
|---|---|
| pyright reportArgumentType | 0 errors（`DayuCliArguments` 满足两个 Protocol） |
| runtime `isinstance(ns, argparse.Namespace)` | `True` |
| runtime `isinstance(ns, DayuCliArguments)` | `True` |
| runtime `ns.research_template_action = 'list'` | 正常赋值 |
| runtime `ns.summary = True` | 正常赋值 |
| MRO | `DayuCliArguments → Namespace → _AttributeHolder → ResearchTemplateDispatchArguments → WriteDispatchArguments → Protocol → Generic → object` |
| `parse_args(namespace=DayuCliArguments())` | 返回 `DayuCliArguments` 实例，所有 argparse 字段正常写入 |
| 模块依赖 | 仅 `argparse` + `typing.Protocol`，stdlib-only |

**优势**:
1. 零 cast/ignore/glue/adapter — Protocol conformance 由继承关系保证
2. 定义顺序自然：Protocol 先声明契约，concrete class 后满足契约
3. `parse_arguments()` 返回类型与 namespace 构造不变
4. Slice 10/11 各自追加 Protocol，`DayuCliArguments` 继承列表原子扩展
5. 后续新增 dispatch Protocol 只需追加一行继承

**风险**:
- MRO: `argparse.Namespace` 是普通 class，Protocol 是抽象 mixin，Python MRO 线性化无冲突。已验证。
- metaclass: `Protocol` 的 metaclass 与 `type`（`argparse.Namespace` 的 metaclass）兼容。已验证。
- argparse `__setattr__`: Protocol data attrs 不在类体定义默认值，argparse 通过 `setattr()` 写入 `__dict__`，无冲突。已验证。
- pyright Protocol data attrs 与 runtime: pyright 将 Protocol data attrs 视为 structural requirement，不要求类体有默认值。多继承后 `DayuCliArguments` 声明满足结构要求。已验证。

### 方案 B: DayuCliArguments 内复制全部字段

在 `DayuCliArguments` 类体中手动声明所有 Protocol 字段。

**REJECTED**: 违反 DRY；`WriteDispatchArguments` 有 15 个字段，复制后 Protocol 定义与 concrete class 定义必须同步维护。且 AGENTS.md 禁止"兼容性 wrapper / facade"。

### 方案 C: 改 selector/entry 类型

将 `_resolve_research_template_action` 参数改为 `DayuCliArguments`，取消 Protocol。

**REJECTED**: Protocol 是 dispatch 层的静态类型边界，selector 只读取 Protocol 声明的字段。取消 Protocol 会将 dispatch 层耦合到 concrete class，违反 AGENTS.md "模块间依赖最小化，优先接口或协议"。

### 方案 D: cast / type: ignore / adapter

在调用处加 `cast(ResearchTemplateDispatchArguments, args)` 或 `# type: ignore`。

**REJECTED**: 违反 AGENTS.md "禁止 cast/ignore/glue/adapter"；掩盖结构性缺陷而非修复。
