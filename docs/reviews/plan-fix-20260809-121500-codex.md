## Precise contract change

- `AcceptancePlan`：保持 schema v2；新增并指纹化三项静态 subprocess env policy 与 owner-derived stable price material ID；download/upload_material/process argv 各含一个 `--quiet`，upload 另显式含 stable `--document-id`。
- `PhaseReceipt`：schema v3；phase 聚合 status/start/end/duration/remaining 保留，执行事实移入 `command_records`。
- `CommandRecord`：index、safe argv、raw argv digest、status、start/end/duration、exit/stop/termination/partial、stdout/stderr SHA-256、有界静态脱敏 stdout/stderr summary、strict evidence union。
- `DownloadCommandEvidence`：ticker/raw+canonical forms/start/end/owner status/summary，以及 downloaded/skipped/failed section status rows；usable discovery 仅 downloaded+skipped，warning count 删除，SEC accession 用固定正字法。
- `MaterialImportCommandEvidence`：owner status/action/stable document ID/条件式 source fingerprint/report date/price JSON SHA/Markdown SHA/repository primary SHA；action 仅 create/update，status=skipped 才走 repository closure。
- `ProcessCommandEvidence`：owner status、filing summary、material counts/TODO 互斥分支；source_kind/status 由六个 section header 派生，stdout 只信 document_id，quality 来自 processed repository。
- prepare 精确 0 record；planned pass 精确全量；failure 仅 executed non-empty prefix；terminal 精确 1 record。v1/v2 receipt 一律拒绝。
