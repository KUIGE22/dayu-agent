## L-02 REJECTION Evidence

**Claim**: `_MissingOffsetTimezone.utcoffset`/`dst` 的 `-> None` 是合法更窄返回类型。

**Evidence**:
1. `tzinfo.utcoffset(dt)` 的 Python 标准库协议返回类型为 `timedelta | None`。
2. 子类将返回类型收窄为 `None` 是类型安全的——每次调用必定返回 `None`，满足父类契约的子集。
3. Pyright 对实现和测试保持 `0 errors, 0 warnings, 0 informations`。
4. 测试目的：构造"存在 tzinfo 但缺失 offset"的反例以触发 `format_utc_seconds` 的防御路径 `value.utcoffset() is None → raise ValueError`。返回 `None` 是实现此目的的唯一方式。
5. 扩大标注为 `timedelta | None` 不会增加测试的表达力或正确性。

**REJECTION 理由充分，无需进一步行动。**
