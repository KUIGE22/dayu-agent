## 2. 选项评估

### 2.1 Option A: 精确私有 TypedDict（推荐）

在同模块新增两个私有 TypedDict，将 `sections` 参数类型从 `list[dict[str, object]]` 改为 `list[_ResearchWorkbookSection]`：

```python
from typing import TypedDict


class _ResearchWorkbookItem(TypedDict):
    """研究手册单项 — 对应 research_workbook JSON 中 section.items[] 元素。"""
    item_id: str
    prompt: str
    status: str
    response: str
    evidence: list[dict[str, str]]
    analyst_notes: str
    evidence_required: bool


class _ResearchWorkbookSection(TypedDict):
    """研究手册章节 — 对应 research_workbook JSON 中 sections[] 元素。"""
    section_id: str
    title: str
    category: str
    items: list[_ResearchWorkbookItem]


def _append_research_workbook_section(
    sections: list[_ResearchWorkbookSection],
    *,
    normalized: str,
    current_title: str,
    current_category: str,
    current_items: list[str],
) -> None:
    """将当前累积的 items 追加为一个新 section 到 sections 列表。

    Args:
        sections: 可变 sections 列表，原地追加。
        normalized: 归一化后的模板名，用于稳定 ID 哈希。
        current_title: 当前 section 标题。
        current_category: 当前 section 分类，空字符串表示无分类（跳过追加）。
        current_items: 当前累积的 prompt 行列表，空列表跳过追加。

    Returns:
        None — 副作用为 sections.append(...)。

    Raises:
        无显式异常。空 category 或空 items 时静默跳过。
    """
```

## 5. 结论

- **Plan line 699 存在类型合约缺陷**：`sections: list[dict[str, object]]` 中的 `object` 违反 AGENTS.md line 37 硬约束。
- **推荐 Option A（私有 TypedDict）**：创建 `_ResearchWorkbookItem` 和 `_ResearchWorkbookSection` 两个模块级私有 TypedDict，将 helper 签名改为 `sections: list[_ResearchWorkbookSection]`。运行时零变化，dict 兼容性完整，mutation 不受影响，pyright 0 errors。
- **不建议 Option B**（保留 `object`）：直接违反硬约束。
- **不建议 Option C**（其他类型方案）：`JsonObject` 涉及跨层反向依赖，union 方案不可维护，Protocol 过度设计。
- **需要 v4.5 plan erratum**：在实施 Slice 4 前修正 plan line 699 的签名为 TypedDict 版本。
- **测试保持通过**：4 个相关测试覆盖的语义（稳定 ID、防碰撞、BOM）在提取后均不变。验证命令 `pytest -k "research_workbook"` + `pyright` 足够。
