#### LOW-01: `validated_fingerprint` 对 `None`/非法类型的异常文本差异

- **文件**: `dayu/services/_write_artifact_utils.py:157`
- **描述**: shared `validated_fingerprint` 对 `None` 输入走 `str(value or "").strip().lower()` → `""` → 校验失败抛 `"{name} must be a sha256 fingerprint"`。HEAD 族 A（`application._validated_fingerprint`）对同一输入先走 `_required_text` → `"{name} must be a string"` 或 `"{name} must not be empty"`。
- **评估**: **设计预期**。plan §1.6.2 C5-CTRL-01 明确指定族 A 策略为 `str(value or "").strip().lower()`，不走 `_required_text`。差分测试 `test_validated_fingerprint_error_text_variants` 已锁定两族错误文本差异。不影响正确性——非法输入始终被拒绝。
- **风险**: 无。Slice 2 迁移 caller 时，族 A 的 7 个调用方已在各自 `_required_text` 校验后传入 text，不会触发此差异。

#### LOW-02: `file_fingerprint` 循环风格微差

- **文件**: `dayu/services/_write_artifact_utils.py:118`
- **描述**: shared 使用 walrus operator `while chunk := stream.read(...)`，HEAD `application._file_fingerprint` 使用 `while True: chunk = stream.read(...); if not chunk: break`。
- **评估**: **语义等价**。两种写法在 chunk 为空时均终止循环。差分测试 `test_file_and_bytes_fingerprints_match_existing_implementations` 已验证输出一致。
- **风险**: 无。

#### LOW-03: `tests/README.md` 新增条目定位

- **文件**: `tests/README.md` diff
- **描述**: 新增一行 `tests/application/test_write_artifact_utils.py` 条目，位于 `test_write_cli_dispatch.py` 之后、`test_host_executor.py` 之前。

| 攻击向量 | 结果 |
|---|---|
| NaN/Inf 输入 | `canonical_json_str`/`canonical_json_bytes`/`serialize_pretty` 均 `allow_nan=False` → `ValueError`。测试 `test_canonical_helpers_reject_non_finite_numbers` 已覆盖 |

| 相对路径注入 | `absolute_path` 在 resolve 前检查 `is_absolute()`。测试 `test_absolute_path_relative_raises` 已覆盖 |
| 控制字符注入 | `require_text` 检查 `ord(c) < 32`。测试 `test_require_text_family_1_behavior` 已覆盖 |
| 空字节指纹 | `bytes_fingerprint(b"")` 返回标准 SHA-256。测试 `test_empty_bytes_have_stable_fingerprint` 已覆盖 |
| naive datetime | `format_utc_seconds` 拒绝无 tzinfo 输入。测试 `test_format_utc_seconds_naive_raises` 已覆盖 |
| 大文件多块读取 | `file_fingerprint` 1MB 块循环。测试用 `b"dayu-artifact-" * 100_000`（~1.4MB）验证 |
