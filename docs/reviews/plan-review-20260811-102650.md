## Closure Evidence

1. **S15-ERR-02 已闭合。** `S15-CTRL-15.2` 已把 acquisition 明确拆为可实现的 descriptor phase 与 member phase：descriptor 以 root-FD-relative component/leaf preflight identity → `O_NOFOLLOW` open → `fstat` exact 绑定，仅读该 FD 一次并由同一 `ExitStack` 持有（计划第 3496–3499 行）；严格解析所得 immutable payload 是 member 的唯一枚举输入，随后全部 member 逐段按相同 identity preflight → no-follow open → `fstat` exact 绑定，且所有 member FD 成功绑定前禁止读取 member bytes（第 3500–3504 行）。这直接消除了上一轮 S15-ERR-02 指出的“未知成员而要求先读全部 leaf”矛盾。
2. **capability 与替换语义完整且诚实。** root 从 filesystem root FD 逐段取得并与 preflight identity exact 对比，最终 root FD 为唯一且持续打开的 capability，禁止按 source-root pathname 重开（第 3489–3494 行）。计划明确不声称 filesystem-wide atomic snapshot：descriptor 在自身 FD 绑定时固定，member set 在全部 member acquisition 完成时固定；preflight 前 regular replacement 只可作为当前 candidate 继续接受 owner/hash 验证，preflight→open component/leaf race 必须拒绝，FD 后 pathname replacement 不得影响已读 bytes（第 3505–3511 行）。
3. **资源生命周期和矩阵可验收。** root/intermediate/descriptor/member FD 在 success、exception、`BaseException` 下都由 `ExitStack` 或等价结构 exact close（第 3511–3512、3546 行）。矩阵分别覆盖 descriptor identity race、descriptor read 后和 lexical enumeration 后 root 替换、member component/leaf preflight→open race、member FD-open 后替换、member preflight 前 regular replacement，以及 snapshot 后所有 reader 分支的替换；并规定 Linux/macOS flags/`dir_fd` 结构受测试约束（第 3535–3548 行）。因此每个时序边界都有可观察的“绑定 FD bytes 或稳定拒绝”oracle，不依赖虚构的全局原子快照。
4. **S15-ERR-01、S15-ERR-03 与架构边界无回归。** canonicalization 仍唯一归 bundle owner，immutable map 固定为 raw canonical absolute string → canonical relative locator → bytes，reader 仅 exact lookup 且零 filesystem I/O（第 3513–3521 行）；`reader=None` 由 golden return/error/warning、filesystem call-order/count 和下游参数保护（第 3529–3534 行）。新增 leaf 仍为 private、仅 owner → neutral leaf 的单向依赖，禁止反向 import，DAG/import smoke 无 cycle；allowlist 仅新增该 leaf 及四个既定透传 owner，未扩大到通用 filesystem framework 或跨层实现（第 3285–3328、3483–3488、3533–3534 行）。
5. **STOP 边界保持有效。** 若需要扩大 owner 白名单、临时落盘 raw bytes、复制 validator、依赖 cooperative filesystem、全局 monkeypatch，或不能在 Linux/macOS 同一 no-follow contract 下闭合，计划要求立即 STOP，不允许降级为最终抛错（第 3697–3709 行）。
