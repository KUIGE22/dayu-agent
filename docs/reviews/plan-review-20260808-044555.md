## 9. 低风险观察（非 findings，仅记录）

### OBS-01 — `functools.partial` 调用计数 gate 的纯 rg 局限性

v4.9 gate "application `functools.partial` 精确 1" 如果用纯 `rg 'functools.partial'` 实现，会匹配 `import functools` 或 docstring 中的字面量。建议 implementation agent 使用 `rg 'functools\.partial\('`（转义括号）或 AST visitor。**不构成 finding**——门禁合同（精确 1 次 partial 调用）的语义已明确，工具选择是实施细节。

### OBS-02 — label "默认" 的静态验证方式

v4.9 gate "label 依次为默认、默认、verification、clearance" 中前两项 "默认" 意味着不传 `run_label` 参数。rg 无法区分 "不传参数" 与 "传 `run_label='configuration-application'`"——两种写法均满足行为等价。建议 implementation agent 用 AST visitor 检查 factory call 的 `keywords` 列表中是否包含 `run_label`，或接受两种写法均通过 gate（行为等价）。**不构成 finding**。

### OBS-03 — `_build_snapshot_for_args` 的 caller 关系

`_build_snapshot_for_args` 与 `build_snapshot_builder` 的关系在 v4.8 和 v4.9 中均未显式澄清（仅 `build_snapshot_builder` factory 有明确的 caller 集合）。若 `_build_snapshot_for_args` 仅服务于 `build_snapshot_builder`，可考虑内联或标注 `_private`。**不构成 finding**——属 v4.8 既有设计问题，不在 v4.9 scope，且不影响循环安全性。
