**发现 1 (Medium)**：`_check_write_model_configuration_manual_recovery_gate`（`_write_manual_recovery.py:1457`）

函数签名只有 `paths_config` 参数，但 docstring 的 Args 段列出了 `args: 解析后的写作命令参数` 和 `paths_config`。`args` 不在签名中。

**证据**：
```python
def _check_write_model_configuration_manual_recovery_gate(
    *,
    paths_config: WorkspaceConfig,       # ← 签名无 args
) -> int:
    """在不启动写作的情况下执行 fail-closed 恢复门禁。

    Args:
        args: 解析后的写作命令参数。      # ← docstring 列出了 args
        paths_config: 写作工作区与配置路径。
    """
```

**根因**：HEAD 版本的英文 docstring 为 `"""Fail closed before normal preflight, approval use, or model work."""`，不含 Args 段。新增中文 docstring 时复制了同模块其他函数的 Args 模板，但未核对签名。

**影响**：文档误导，不影响运行时。

**最小修复**：删除 docstring 中的 `args: 解析后的写作命令参数。` 行。
