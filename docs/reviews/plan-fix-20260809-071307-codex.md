### 闭包精确语义

- research-template tree 按包相对 POSIX path 排序，对每个 regular `.md`/`.definition.json` 文件绑定 locator + bytes SHA-256，再得到 tree fingerprint。
- 至少包含 `common.md`、`technology.md`、`common.definition.json`、`technology.definition.json`；也覆盖 `consumer.md` 等 package manifest 会枚举/消费的其它研究资产。
- 根级 `定性分析模板.md` 不在 research-template 子目录，因此用独立 SHA-256 进入同一 plan fingerprint。
- tree 遇到 symlink、非 regular file 或重复 canonical locator 即 fail closed。
- 用户 workspace 自定义模板仍不参与，`--research-base` 仍只控制派生产物落点。

### 回归与 drift 契约

Slice 1/2 现要求分别改动以下任一资产都使 tree/plan fingerprint 改变，并在 subprocess 前 fail：

- 根级 `定性分析模板.md`；
- `technology.definition.json`；
- `common.md` / `technology.md`；
- 任一其它 package manifest 会枚举/消费的研究资产，例如 `consumer.md`。
