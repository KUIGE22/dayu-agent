## 2. S5-CTRL-02: 13 个 patch 迁真实 owner、Python function globals、禁止 compat re-export

### 2.1 Python function globals 行为验证

v4.6 L840-843 声明:

> 这 8 个 private import 均由 `run_write_command` 或迁移期间的真实 caller 使用，必须保持 `dayu.cli.commands.write.<private>` direct import/monkeypatch 和 global lookup 行为；不得添加 compatibility re-export、wrapper、lazy import 或同步 seam。

**Python 机制验证**:

```
# write.py (Slice 5 后)
from ._write_params_validation import _challenger_requested  # 写入 write.__dict__

# run_write_command 在 write.py 中:
if _challenger_requested(args):  # lookup in write.__globals__
    ...
```

- `run_write_command` 的 `__globals__` 是 `write.__dict__`
- `_challenger_requested` 通过 import 写入 `write.__dict__`
- monkeypatch `write._challenger_requested = lambda _: True` 替换 `write.__dict__["_challenger_requested"]`
- `run_write_command` 在 call time lookup 到 patched 版本 ✅

**但 `_validate_research_materialization_args` 内部调用链**:

```
# _write_params_validation.py (定义位置)
def _validate_research_materialization_args(args):
    ...
    challenger_requested = _challenger_requested(args)  # lookup in _write_params_validation.__globals__
```

- `_validate_research_materialization_args` 的 `__globals__` 是 `_write_params_validation.__dict__`
- 内部 `_challenger_requested` lookup 在 `_write_params_validation.__dict__`，不在 `write.__dict__`
- monkeypatch `write._challenger_requested` **不影响** `_validate_research_materialization_args` 内部调用

**实际影响评估**: 源码中无测试同时 (a) patch `write._challenger_requested` 且 (b) 调用真实 `_validate_research_materialization_args`。测试行 5928 patch `_validate_research_materialization_args` 为 `lambda _: None`（整体替换），内部 `_challenger_requested` 不被调用。其他测试直接构造 args 让 `_challenger_requested` 自然返回正确值。**无实际 breakage**。
