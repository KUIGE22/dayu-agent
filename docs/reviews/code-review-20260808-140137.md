### O-1: `_handle_config_change_approval` 函数长度

**分类**: pre-existing，non-blocking，out-of-scope for Slice 12。

### O-3: `_handle_config_change_request_export` 双重防御

L347-352 检查 `challenger_promotion_proposal_input is None` 时 raise `ValueError`，但 gate（L147-155）已在上游确保 `challenger_config_change_request_output is not None` 时 `challenger_promotion_proposal_input` 必须非 None。这是 helper 的内部不变量防御（defense-in-depth），gate 通过后不会触发。docstring 的 Raises 段正确记录了此异常。

**分类**: intentional defense-in-depth，non-blocking。
