## Findings

### S31-AUTH-CR01-未修复-中-授权查询会在 SQLAlchemy INFO 日志中写出 token hash

- **入口/函数**: `authorize_active_actor` 和 `authorize_reviewer` → `_token_hash` → `_auth_row` → `Session.execute`；平台会话由 `create_platform_engine` 构造。
- **文件(行号)**: `dayu/investment/storage/_evidence_review_auth.py:363-367,403-407,332-335`；`dayu/investment/storage/db.py:80-94`；测试空白在 `tests/integration/investment/test_postgres_evidence_auth.py:547-593`。
- **输入场景**: 合法或形态合法但未授权的合成 bearer，经平台 Engine 发起授权；运行进程把 `sqlalchemy.engine.Engine` logger 设为 INFO，例如启用 SQL 诊断日志。
- **实际分支**: `_token_hash` 形成 SHA-256 hex；`_auth_row` 把它放进 `token_hash` bind；SQLAlchemy Engine 在执行查询时把绑定参数输出到 INFO logger。查询成功、拒绝或随后异常脱敏均已无法撤回此日志副作用。
- **预期行为**: 接受计划 §3.3 明定 raw/hash 不进日志；任何受支持的 caller Session 都应在绑定 hash 前满足参数隐藏约束，否则 fail closed。
- **实际行为**: `create_platform_engine` 只传 `echo=False`，Engine 的 `hide_parameters` 为 `False`。同一工厂创建的 Engine 在该 logger 为 INFO 时，参数日志包含完整 64 位合成 token hash。外部提供的 Session 也没有任何 Engine 参数隐藏校验。
- **直接证据**: 生产代码 `_auth_row:332-335` 直接以字典 bind `token_hash`；`db.py:94` 调用 `create_engine(dsn, echo=False)`。独立复现使用同一 `create_platform_engine` 与合成 64 位 hex bind 执行 `SELECT :token_hash`：`factory_engine.hide_parameters False`、`hash_logged True`，日志中出现一行完整 bind 参数；改用 `create_engine(..., hide_parameters=True)` 后 `hash_logged False`，日志显示 `[SQL parameters hidden due to hide_parameters=True]`。该实验采用 SQLite 连接验证 SQLAlchemy Engine 的通用记录路径；授权数据库主链另在真实 PG16 通过，不把 SQLite 实验冒称为 RLS/授权证明。现有异常测试只检查 `__context__`/traceback，没有检查 Engine logger。
- **影响**: 违反本片明确的 hash 保密合同；开启常规 SQLAlchemy INFO 诊断时会形成持久 token verifier 及跨日志关联材料。高熵 bearer 的 hash 不能据此直接反推出 bearer，因此本项为中等严重度，不主张已发生身份冒用。
- **建议改法和验证点**: 先由 Controller 扩充 §2 allowlist，允许在受控 `create_platform_engine` 中设置 `hide_parameters=True`；同时在 helper 接受任意 caller-provided `Session` 的现有签名下，绑定 hash 之前检查实际 Session bind 的 Engine/Connection 已启用隐藏参数，缺失则固定脱敏错误并不执行授权 SQL。两层缺一会分别漏掉默认工厂或外部 Engine。用 INFO logger 的真实 helper PG 调用与外部非隐藏 Engine 负例验证日志中没有 synthetic hash，保持现有 READ COMMITTED/RLS 测试通过。
- **修复风险（中）**: `db.py` 不在已接受 S31-Auth allowlist；需先修订计划范围并核既有 Engine 使用者的参数日志预期，不能在本片擅自改动。
