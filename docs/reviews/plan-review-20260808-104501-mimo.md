**Spike 2: 显式字段 + structural subtyping — `DayuCliArguments()` 实例化**:

**Spike 3: 显式字段 — 类型流转**:
```python
def _resolve(args: ResearchTemplateDispatchArguments) -> str:
    return str(getattr(args, "research_template_action", "") or "").strip().lower()

def _check(args: WriteDispatchArguments) -> bool:
    return args.summary

def run(args: DayuCliArguments) -> int:
    action = _resolve(args)  # structural subtyping OK
    s = _check(args)          # structural subtyping OK
    return 0
```


### 1.3 根因分析

初审 103001 的验证缺失：只测试了参数传递兼容性（`_resolve(args)` 调用）和 runtime 行为，未测试 `DayuCliArguments()` 实例化点。pyright 将 Protocol data attributes 视为 abstract members；多继承后 `DayuCliArguments` 声称满足 Protocol 但未实现 abstract members，实例化被拒绝。

Controller erratum §1 正确指出: "MiMo 的 runtime/MRO/argparse 证据只证明 Python 运行时可工作，未覆盖这个静态实例化门禁"。

### 1.4 裁决

初审方案 A（Protocol 多继承）**REJECTED**。Controller 裁决正确。
