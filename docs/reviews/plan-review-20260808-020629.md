## 1. Dual-Owner 语义精确区分

### 1.1 两个 globals owner 的源码证据

| Owner | 定义位置 | 被谁 lookup | call site 源码行 |
|-------|----------|------------|-----------------|
| `write._challenger_requested` | `write.__dict__`（通过 import） | `run_write_command.__globals__` = `write.__dict__` | L4829: `if ... and _challenger_requested(args):` |
| | | | L5079: `if _challenger_requested(args):` |
| | | | L5191: `if _challenger_requested(args):` |
| `_write_params_validation._challenger_requested` | `_write_params_validation.__dict__`（定义模块） | `_validate_research_materialization_args.__globals__` = `_write_params_validation.__dict__` | L3595: `challenger_requested = _challenger_requested(args)` |

**Python 规范**: 函数对象在定义时绑定 `__globals__` 为其所在模块的 `__dict__`。函数体内自由变量解析始终查找此 `__globals__`，不查找调用栈上任何模块。

**结论**: monkeypatch `write._challenger_requested` 仅影响 `run_write_command` 的 3 个 global call site；monkeypatch `_write_params_validation._challenger_requested` 仅影响 `_validate_research_materialization_args` 内部调用。两者独立受控，无交叉影响。v4.6 plan 精确区分 ✅
