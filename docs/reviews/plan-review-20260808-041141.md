## 3. Callable 方差声明验证

### 3.1 计划声明（line 1084–1088）

> `Callable` 的参数类型是逆变的，因此一个接受较宽 `argparse.Namespace` 的 runner 理论上可赋给 `Callable[[DayuCliArguments], int]`；本计划仍将 39 个 runner 机械收窄，是为了终态 API 一致、owner 清晰与 targeted rg 可审计，不得把相反的协变/逆变论断写成迁移必要性。

### 3.2 方差分析

`Callable[[T], R]` 的参数位置 `T` 是**逆变**的：
- 若 `A <: B`，则 `Callable[[B], R] <: Callable[[A], R]`
- `DayuCliArguments <: argparse.Namespace`（子类关系）
- 因此 `Callable[[argparse.Namespace], int] <: Callable[[DayuCliArguments], int]`

即：接受 `argparse.Namespace` 的函数**可以**赋给 `Callable[[DayuCliArguments], int]` 类型的变量。

### 3.3 计划声明正确性

| 声明 | 判定 |
|---|---|
| "参数类型是逆变的" | ✅ 正确 |
| "接受较宽 `argparse.Namespace` 的 runner 理论上可赋给 `Callable[[DayuCliArguments], int]`" | ✅ 正确 |
| "机械收窄是为了终态 API 一致、owner 清晰与 targeted rg 可审计" | ✅ 合理工程决策 |
| "不得把相反的协变/逆变论断写成迁移必要性" | ✅ 正确——逆变允许宽参数，但收窄是为了可审计性，不是类型系统强制 |
