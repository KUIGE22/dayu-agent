### #3 MEDIUM — dataclass 留置 research_template.py 会引入 import cycle

**位置**: `docs/plans/2026-08-07-cli-write-architecture-refactor.md` §1197 行

**问题**: 计划明确 "保留 `ResearchTemplate`/`ResearchTemplateRecommendation` 数据类" 在 `research_template.py`，但未说明 import 方向。AST 验证发现:

1. `list_research_templates()` → 迁入 `_research_template_core.py`，返回 `tuple[ResearchTemplate, ...]`，需 import `ResearchTemplate`
2. `recommend_research_templates()` → 迁入 `_research_template_core.py`，返回 `tuple[ResearchTemplateRecommendation, ...]`，需 import `ResearchTemplateRecommendation`
3. `_recommendation_payload()` → 迁入 `_research_template_helpers.py`，使用 `ResearchTemplateRecommendation`

若 dataclass 留置 `research_template.py`:
```
research_template.py → _research_template_core.py  (import extracted functions)
_research_template_core.py → research_template.py   (import ResearchTemplate dataclass)
→ ImportError: partially initialized module (CYCLE)
```

**Fix**: 将 `ResearchTemplate` 和 `ResearchTemplateRecommendation` 迁入 `_research_template_helpers.py`（叶子模块，零入度）。`research_template.py` 和所有其他模块均从 helpers import 这两个 dataclass。这是唯一不引入 cycle 的归属方案。

**影响**: helpers 模块新增 2 个 ClassDef（从 19 函数变为 19 函数 + 2 dataclass），research_template.py 终态不再包含 dataclass 定义。
