#### LOW-01: `items` 局部变量名遮蔽

**位置**：`research_workbook.py` line 61 vs line 115

**描述**：helper 内部的 `items: list[_ResearchWorkbookItem] = []`（构造新 item 列表）与外层的 `items = section["items"]`（读取已有 items）同名但不同作用域。提取为模块级函数后，helper 内的 `items` 成为函数局部变量，外层的 `items` 成为 `build_research_workbook_payload` 的局部变量，作用域完全隔离。

**风险**：零。Python 作用域规则保证无冲突。但建议在 helper docstring 中注明 `items` 是内部构造变量，非参数。

**阻塞**：否。

#### LOW-02: `from __future__ import annotations` 对 TypedDict runtime introspection 的影响

**位置**：`research_workbook.py` line 3

**描述**：`from __future__ import annotations` 使所有注解在运行时变为字符串（PEP 563）。TypedDict 的 `__annotations__` 在运行时是 `{'item_id': 'str', ...}` 而非 `{'item_id': <class 'str'>, ...}`。这对 pyright 静态分析无影响，但如果未来有代码在运行时检查 TypedDict 的 `__annotations__`（如 JSON Schema 生成），需要注意。

**当前影响**：零。`research_workbook.py` 中无运行时注解检查代码。

**阻塞**：否。

#### LOW-03: `total=True` 与未来 schema 演进

**位置**：三个 TypedDict 定义

**描述**：TypedDict 默认 `total=True`（所有字段必需）。当前 helper 只构造（不从 JSON 读取），所有字段始终显式赋值，`total=True` 完全正确。但如果未来 schema 版本新增可选字段（如 `tags: list[str]`），需要改用 `NotRequired` 或拆分 TypedDict。

**当前影响**：零。当前 schema 无可选字段。

**阻塞**：否。
