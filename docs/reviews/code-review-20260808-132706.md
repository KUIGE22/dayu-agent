关于 wrapper：`_run_write_command_with_complete_dispatch_args`（challenger 测试）和 `run_write_command`（engine 测试）使用 `args.__dict__.setdefault(field, False/None)` 补齐 parser 默认值。这是测试边界补偿——直接 `DayuCliArguments(...)` 构造不含 argparse 自动写入的默认值。生产路径 `parse_arguments()` 通过 `parser.parse_args(namespace=DayuCliArguments())` 原位填充全部字段，由 `test_parse_arguments_returns_real_dayu_namespace` 验证。**【LOW】** 若 `DayuCliArguments` 类体删除某 Protocol 字段，AST 结构测试 `test_protocol_and_dayu_fields_form_exact_union` 会失败，但使用 wrapper 的运行时测试不会失败（`setdefault` 仍能设置动态属性）。双重覆盖下风险可控。
