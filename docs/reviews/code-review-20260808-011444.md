## 4. Adversarial Failure Review

### 4.1 重复输入 ID 碰撞

**攻击向量**: 两个不同 section 具有相同的 `(normalized, category, title)`。

**防御**: `section_index = len(sections)` 在每次 append 前取值，即使 title/category 相同，index 不同导致 hash 不同。

**结论**: 安全。35 项聚焦测试中的重复 heading/bullet 测试已覆盖。

### 4.2 空 items 列表行为

**攻击向量**: 模板中某 section 有 heading 但无 bullet。

**防御**: `if not current_category or not current_items: return`。空 items 被跳过，不产生空 section。

**结论**: 安全。与原 nested 闭包行为一致。

### 4.3 UTF-8 BOM 处理

**攻击向量**: 模板文件带 BOM。

**防御**: `template_path.read_text(encoding="utf-8-sig")` 正确剥离 BOM。

**结论**: 安全。

### 4.4 TypedDict 与 `dict[str, object]` 的类型兼容性

**攻击向量**: `sections.append({..., "items": items})` 中 `items: list[_ResearchWorkbookItem]` 能否赋值给 `list[_ResearchWorkbookItem]`？

**分析**: TypedDict 实例是 `dict[str, object]` 的子类型。字面量 `{...}` 的所有字段匹配 `_ResearchWorkbookSection` 的 required keys。pyright 验证 0 errors。

**结论**: 安全。

### 4.5 `build_research_workbook_payload` 中 `str(section["category"])` 的类型安全性

**分析**: `section` 现在是 `_ResearchWorkbookSection`（TypedDict），`section["category"]` 的静态类型是 `str`。`str(...)` 调用是冗余但无害的。
