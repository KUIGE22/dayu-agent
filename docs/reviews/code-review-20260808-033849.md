**位置**: `_write_config_helpers.py:87-107`

**性质**: 从旧 `write.py` 原样迁移的既有模式，非本 Slice 引入。违反编码硬约束"使用 getattr 必须有充分理由"的精神，但不影响正确性。

**建议**: Slice 6-8 后续清理时统一替换为直接属性访问。不阻塞本 Slice。
